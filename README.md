## Summary
Python code to test how increasing parameters in a polynomial fit affects the quality of the fit.  
This analysis was completed using [data from Our World in Data](https://ourworldindata.org/grapher/long-term-cod-catch). 

## Output  
**Graph 1**  
A line graph showing the population of the cod between 1920 and 2010.  
Polynomial fits with orders from 1 to 10 are imposed over the top using Polyfit.   
**Graph 2**    
Uses chi squared to produce a line graph showing how the number of polynomial coefficients affects quality of fit in Graph 1.  
**Graph 3**     
Uses the Bayesian Information Coefficient to produce a line graph showing how the number of polynomial coefficients affects quality of fit in Graph 1.  

## Execution
Can be run using a normal VSCode setup or Python interpreter.
